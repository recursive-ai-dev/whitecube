# Whitecube Desktop — Prioritized Improvement Plan (0.9.4)

Ordered from most negatively affecting the application (use-after-free, scene-graph leaks, and Wayland event-loop stalls) down to minor validation and edge-case hardening.

- [x] **1. Compositor output hotplug safety (`src/whitecube.c`)**: Fix `output_destroy` leaving dangling `t->output` and `ls->output` pointers, leaking `o->bg_tree` and `o->tab_tree` scene trees, and failing to clear/rebuild toplevel tab scene nodes (`t->tab_border`, `t->tab_cube`, `t->tab_label`) and retile remaining outputs when a monitor disconnects.
- [x] **2. Wallpaper supervisor Wayland poll race (`src/cube-ca.c`)**: Replace the race-prone `wl_display_dispatch_pending` + `poll` + `wl_display_dispatch` sequence in `supervisor_main` with the canonical `wl_display_prepare_read` / `wl_display_flush` / `wl_display_read_events` / `wl_display_cancel_read` protocol so queued Wayland events never stall behind timer wakeups.
- [x] **3. Settings subprocess reaper non-blocking poll (`src/cube-settings.c`)**: Eliminate the 2 ms synchronous `usleep(200)` spin loop in `job_read` when child pipes close before process exit, and instead use a short poll timeout in the main event loop while an EOF-drained job awaits `waitpid(WNOHANG)` reaping.
- [x] **4. Settings table & status bar OOM safety (`src/cube-settings.c`, `src/cube-status.c`)**: Check `strdup` and `realloc` return values in `table_set` (preventing pointer leaks and NULL dereferences on allocation failure) and check `calloc` / `wl_shm_pool_create_buffer` in `cube-status` `paint()` (cleaning up the shared-memory mapping and pool on failure).
- [x] **5. Config line-truncation hardening & `tab_h` clamping (`src/cube-status.c`, `src/whitecube.c`)**: Drain overlong lines (`> 255` bytes) in `read_geometry` (`src/cube-status.c`) and `saved_output` (`src/whitecube.c`) so truncated comments or values cannot forge subsequent entries, strip key/value whitespace, and clamp `tab_h` to `[20, 80]` in both `read_geometry` and live `status_preference` updates.
- [x] **6. ALSA TLV dB overflow & WAV parser hardening (`src/cube-audio/cube-audio.c`)**: Compute ALSA `SNDRV_CTL_TLVT_DB_SCALE` maximum dB in `elem_db` via `db_scale_range` using 64-bit integer arithmetic with bounds checks (`raw_max > raw_min`, `step_db > 0`) to prevent 32-bit signed overflow UB, and reject WAV files with duplicate `fmt ` chunks, `EOF` on padding, or zero audio frames (`data_left < align`).
- [x] **7. Cosmos heightfield reentrancy & preview cleanup (`src/cube-cosmos.h`, `src/cube-ca.c`)**: Replace the mutable `static float hh` buffer in `cos_land` with stack storage so terrain rendering is reentrant, and free all simulation allocations (`c.f.a`, `c.f.b`, `c.stars`, `c.cos`, `c.b[0].px`) via `cosmos_offscreen_free` on early error returns in `cosmos_offscreen`, `preview`, and `preview_zoom`.
- [x] **8. Cube Player speed control & CLI cleanup (`apps/cube-player/src/main.c`)**: Make the transport bar `A_SPEED` action update `p->speed` and `a->state.speed` deterministically (matching `A_SLOWER`/`A_FASTER`), and route invalid `--theme` CLI exits through `cleanup` so initialized state and GLib arrays are freed.
- [x] **9. Cube Player malformed URL title safety (`apps/cube-player/src/state.c`)**: Guard `media_title` against `g_uri_get_host(u)` returning `NULL` or empty on malformed `://` strings so `g_uri_unescape_string` is never called with a `NULL` pointer.
- [x] **10. Preferences keyboard config parsing & lock FD cleanup (`bin/cube-preferences`)**: Strip whitespace around keys/values and ignore leading-whitespace comments when `validate_keyboard` reads `/etc/whitecube/config` and `~/.config/whitecube/config`, and close `preferences.lock` in a `finally` block.
- [x] **11. Session crash-recovery log tail & audio setting normalization (`bin/whitecube-session`)**: Discard any partial first line when seeking to a byte offset in `crash_recovery` so truncated UTF-8 sequences or mid-line fragments are not printed, and normalize `audio_setting` to `'alsa'` or `'pipewire'`.
- [x] **12. Strict hex color length validation (`src/whitecube.c`, `src/status-theme.h`)**: Require exactly 6 hex digits (after optional `#` and whitespace trimming) in `parse_hex` and `status_theme_color` so 3-digit or 7+-digit strings are rejected instead of truncated.
